# RTO Analyzer: Return-to-Origin & Failed Delivery Pattern Analyzer

An integrated project combining **Advanced Java**, **Advanced DBMS**, **Statistics with R** and **Open Source Technologies**.

Online sellers lose money when parcels fail delivery and return to origin (RTO). This system manages the shipment lifecycle, records every delivery attempt, and uses statistical analysis to find what drives failures.

> **Data note:** the dataset is **simulated** (2,000 shipments) with planted patterns, generated by `r/seed_data.R`. Results show the method works, not real-world courier performance.

## Architecture

```
Browser (JSP + JSTL)
      |
Spring Boot (MVC, Filter, @Transactional service, state machine)
      |  JDBC (JdbcTemplate, PreparedStatement)
MySQL 8.4 (3NF schema, trigger, JSON column, indexes, view)
      ^  RMariaDB                      |
R (statistics + charts) <-- launched by Java via ProcessBuilder
```

1. Java writes shipments and delivery attempts to MySQL inside transactions.
2. A MySQL trigger records every status change in `status_audit`.
3. Clicking **Run R Analysis** makes Java launch `r/analysis.R`.
4. R reads MySQL, runs the tests, writes results to `analysis_results` and saves charts.
5. Java displays results, insights and charts on the Analytics page.

## Shipment state machine

```
CREATED -> SHIPPED -> OUT_FOR_DELIVERY -> (attempt) -> DELIVERED
                            ^                  |
                            +-- ATTEMPT_FAILED <+  (3rd failure -> RTO)
```

Illegal transitions are rejected in the service layer. Attempt logging runs in one transaction: lock row, insert attempt, update status and insert RTO cost all commit or roll back together.

## Key findings (simulated data)

- COD RTO rate **21.7%** vs prepaid **10.8%** (two-sample proportion test, p < 0.001)
- PinPoint Couriers has the highest attempt failure rate (**63%**) and is the slowest (**5.0 days** to first attempt, ANOVA F = 329.6)
- Morning delivery slots fail most (**55.6%**)
- Observed RTO **16.9%** vs **12.8%** expected under independence: failures cluster on the same customers
- RTO loss ≈ **Rs 23 per kg + 25% of order value** (MLR, R² = 0.998, high because the cost follows a fixed formula)

## Setup

Requirements: Java 17+, MySQL 8.x, R 4.x with `DBI` and `RMariaDB`.

```bash
# 1. Database
mysql -u root -p < db/schema.sql
Rscript r/seed_data.R
mysql -u root -p < db/advanced.sql

# 2. Credentials (never committed)
echo "spring.datasource.password=YOUR_PASSWORD" > local.properties
# R reads credentials from ~/.my.cnf  ([client] user=... password=...)

# 3. Run
./mvnw spring-boot:run
# open http://localhost:8080
```
